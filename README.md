# CyberSecurity Device Manager

Ushbu loyiha qurilma xavfsizligi, messenjerlar monitoringi va real vaqt rejimida admin bilan muloqot qilish tizimini o'z ichiga olgan Flask veb-ilovasidir.

## Asosiy imkoniyatlar
- User registration va login (sozlamalar bo'limi bilan)
- Circle virus checker va device health monitoring
- Messenjer va ilovalar kesimida kesh tozalash hamda shubhali xabarlarni tekshirish
- Admin paneli (`/admin`) orqali real vaqtda foydalanuvchilar va qurilmalarni boshqarish
- Operatorlar ro'yxatini boshqarish
